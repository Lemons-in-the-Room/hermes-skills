# Lemons in the Room: Hermes skills

Shared Hermes skills for the team.

## Install (once)
```
hermes skills tap add Lemons-in-the-Room/hermes-skills
hermes skills search lemonsintheroom
hermes skills install Lemons-in-the-Room/hermes-skills/skills/lemonsintheroom-skill
```
Requires GitHub access to this repo (`gh auth login`, or a GITHUB_TOKEN).

## Update
```
hermes skills check
hermes skills update
```

## Contribute
Edit `skills/lemonsintheroom-skill/`, open a PR. Source of truth for facts is Notion. No secrets in this repo.
